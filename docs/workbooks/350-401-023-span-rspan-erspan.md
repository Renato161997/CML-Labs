# Local and Remote SPAN Visibility

## Scope and prerequisites

Two IOL-L2 switches, two Net-Tools endpoints and one automation capture guest implement RSPAN. VLAN 10 forwards the actual HTTP service across the trunk; VLAN 999 carries the separate remote mirror. Removing only 999 from SOURCE trunk must leave HTTP healthy while the remote receiver proves a full selected-packet quiet window. Re-allowing 999 must recover a fresh-port PCAP. The measured scope is remote source/destination sessions and VLAN transport. ERSPAN IP/GRE encapsulation is a separate design boundary and is not established by this RSPAN evidence. Nominal RAM is 4 GiB. The receive-only observer opens an actual Linux AFPacket socket in the isolated capture guest, requests promiscuous membership and filters only a fixed benchmark HTTP GET tuple. A successful capture requires a real one-frame Ethernet PCAP with consistent lengths, tuple and SHA256; a scalar claim without that file is rejected. Negative visibility requires the real bound listener to finish the entire 12-second window. This is absence of the selected fixture request, not absence of all network traffic. Phase-specific ports prevent old frames from satisfying recovery. The parser handles up to two VLAN tags and complete unfragmented IPv4/TCP GET packets; it is not a general PCAP/PCAPNG or TCP reassembly analyzer and does not validate transport checksums. No packet is transmitted by the observer. All endpoint/switch consoles are opened before arming, so console initialization does not consume the observation window. Primary configuration reference: https://www.cisco.com/c/en/us/td/docs/IIOT/switches/ie3x00/config/layer2/layer2_switch/g_configuring-span-and-rspan/configure-span-rspan.html . IOL-L2 feature support is accepted only if the recorded real-frame gates pass, not from accepted CLI text or vendor support inference.

Use licensed reference images for cml-labs-toolbox, ioll2-xe, net-tools in CML 2.10.1. All addresses are educational. No Internet, external connector or production credentials are required. Starting state: Working isolated reference baseline. Functional status and exact tested images: [results](../../validation/RESULTS.md).
